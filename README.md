# AAZ LegacyChat for iOS 16

LegacyChat is an experimental build created to provide a cleaner and more reliable way to access ChatGPT and modern web content on legacy iOS devices. It focuses on fixing compatibility issues, keeping essential features such as photo upload and image paste working, and removing unnecessary permissions and unsupported components.

## Download

Download the latest IPA from Releases and install it using TrollStore Lite.

## Compatibility

Tested on:

- iPhone running iOS 16.7.16
- iPad running iPadOS 16.6

Photo upload and image paste are supported.
